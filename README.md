# Django

>Projeto de Django de Gestão de Financeira.

---

## 📌 Sobre o Projeto

Paginas de login,registro de usuario,funcionalidades de editar,excluir e incluir nas informações.

### ✨ Funcionalidades

- [x] Tela de Login
- [x] Tela de Registro
- [x] Tela de Adicionar,exluir e editar 

---

## 🛠️ Tecnologias Utilizadas

Listagem das principais ferramentas, linguagens e frameworks utilizados:

-**Linguagem:** Python 3.x
- **Framework Web:** Django
- **Frontend:** HTML5, CSS3 (`style.css`)
- **Banco de Dados:** SQLite3 (`db.sqlite3`)
- **Ambiente Virtual:** `venv`
